A — Barra inferior (Bottom Nav)

As abas principais ficam na barra inferior, acessível com o polegar. Abas secundárias em um menu "Mais". Padrão de apps mobile modernos.

Prós

  • Ergonomia excelente no celular
  • Sempre visível
  • Familiar para usuários mobile

Contras

  • Menos espaço vertical para conteúdo
  • Comportamento diferente no desktop

B — Hamburger (menu deslizante)

Ícone ☰ no header abre uma sidebar que desliza sobre o conteúdo. Comum em dashboards web.

Prós

  • Máximo espaço para conteúdo
  • Mesmo padrão desktop e mobile

Contras

  • Navegação escondida — 2 toques para trocar de aba
  • Menos ergonômico no celular

C — Icon Rail (sidebar estreita com ícones)

Sidebar sempre visível com apenas ícones. No mobile ocupa pouco espaço (36–40px). No desktop pode expandir com label ao hover.

Prós

  • Sempre acessível, 1 toque
  • Consistente desktop/mobile
  • Espaço mínimo usado

Contras

  • Ícones precisam ser autoexplicativos
  • No mobile muito estreito pode ser difícil de tocar
